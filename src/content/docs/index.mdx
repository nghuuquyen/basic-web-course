## Final Project

<Aside type="tip" title="Chiếm 50% điểm tổng kết">
Làm nhóm 2–3 người, xây một web application hoàn chỉnh qua **5 tasks**:

| Task | Nội dung | Điểm |
|---|---|---|
| Task 1 | Project planning — wireframe, GitHub setup, phân công | 2 |
| Task 2 | Implement UI — Tailwind, JavaScript, responsive | 3 |
| Task 3 | Database Integration — schema, dynamic pages | 2 |
| Task 4 | Optimization — Lighthouse, Analytics, Sentry | 1 |
| Task 5 | UI/UX Peer Review — review nhóm khác, implement feedback | 2 |

**Deliverables:** Source code trên GitHub · README với ERD và screenshots · Video demo YouTube (≤ 10 phút)

[Xem chi tiết Final Project Brief →](/basic-web-course/final-project-brief)
</Aside>
